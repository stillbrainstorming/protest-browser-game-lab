# Jantar Mantar Chalo · Crowd Rally Simulator

> A browser crowd rally simulation and arcade sandbox, faithful to [mantarjantar.com](https://mantarjantar.com) and adapted for GitHub Pages and mobile PWA installation.

## Overview

**Jantar Mantar Chalo** is an arcade crowd simulation set on the streets of Delhi leading towards Jantar Mantar. Play as an **Andolankari** leading a peaceful rally or as the **Dilli Police** maintaining public order.

The project runs completely client-side in the browser with full offline bot simulation, physics, sound effects, touch and mouse/keyboard controls, and PWA capabilities.

## Features

- **Full In-Browser Simulation Engine**: Complete autonomous AI crowds, barricade collision physics, media crews, and city landmarks simulated locally in real-time.
- **Two Playable Roles**:
  - ✊ **Andolankari (Assembly Leader)**: Walk into passers-by to grow your kafila, push through barriers, dodge water cannons and tear gas, reach Jantar Mantar, and hold the assembly.
  - 👮 **Dilli Police**: Maintain order, use lathis to disperse unruly crowds, deploy tear gas cannisters, and guide leaders onto transit buses.
- **Interactive Delhi Map**: Featuring Connaught Place, Patel Chowk, Janpath, Bangla Sahib, metro stations, street food stalls, and CCTV zones.
- **Touch & Desktop Controls**:
  - **Mobile / Touch**: Virtual joystick with run drag, custom on-screen action buttons with drag-and-drop button repositioning.
  - **Desktop**: Mouse aim-and-click movement, right-click sprinting and tear gas aiming, customizable keyboard shortcuts.
- **Progressive Web App (PWA)**: Installable directly to your home screen on iOS, Android, macOS, and Windows with offline caching.
- **Zero Backend Required**: Ready for GitHub Pages deployment out of the box.

## How to Play

### Controls
| Action | Andolankari (✊) | Police (👮) |
|---|---|---|
| **Move** | Point mouse or drag joystick | Point mouse or drag joystick |
| **Run / Dash** | Hold Right-Click or drag joystick far | Drag joystick far |
| **Action** | Left-Click (Slogan / Push Barricade) | Left-Click (Lathi swing) |
| **Special** | Hold Click at barricades to push | Right-Click to aim & throw tear gas |
| **Shortcuts** | <kbd>M</kbd> Mute · <kbd>Q</kbd> Quality · <kbd>T</kbd> Switch Team · <kbd>Esc</kbd> Menu |

## Deploy to GitHub Pages

1. In your GitHub repository, navigate to **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
3. Select branch `main` and folder `/ (root)`, then click **Save**.
4. The site will be live at `https://<username>.github.io/<repo-name>/`.

## Progressive Web App (PWA)

To install on mobile devices:
- **Chrome / Android**: Tap the three-dot menu and select **Add to Home screen** or **Install app**.
- **Safari / iOS**: Tap the Share button and select **Add to Home Screen**.
