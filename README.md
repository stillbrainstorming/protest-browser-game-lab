# Protest Browser Game Lab

An original, fictional, non-political arcade sandbox built for static hosting.

## Play
- Pick one of two fictional roles: **Pathfinder** or **Beacon**.
- Move around the arena, collect glowing tokens, and invite neutral crowd characters to follow.
- Avoid obstacles and use the role action to create a brief pulse.
- Keyboard: WASD or arrow keys to move, Space for action, P to pause. Touch: use the on-screen direction pad and action button.
- Practice mode and a local score; no server or multiplayer backend.

## GitHub Pages
Open `index.html` locally, or publish from **Settings → Pages → Deploy from a branch → main → / (root)**.

All characters, setting and artwork are fictional and original. No real political figures, parties, or copied third-party assets are included.
